# Frontend Development Instructions

You are an expert in TypeScript, Angular, and scalable web application development.

Write functional, maintainable, performant, and accessible code following Angular and TypeScript best practices.

## Angular Rules

For all Angular and TypeScript implementation decisions, follow:

`docs/angular/angular-best-practices.md`

Treat this document as the primary source of Angular coding conventions for this project.

## Design Reference

For UI implementation, follow the design reference in:

`docs/design/index.html`

Use it as the primary visual reference for:

- layout
- spacing
- typography
- colors
- borders
- border radius
- buttons
- form controls
- cards
- responsive behavior
- overall visual hierarchy

Do not copy the static HTML architecture directly if it conflicts with Angular best practices.

Recreate the design using proper Angular components, reusable UI patterns, accessibility requirements, and the conventions defined in `docs/angular/angular-best-practices.md`.

When implementing a new page or feature, inspect the relevant parts of the design reference before writing the UI.
